What the mini-check looks at

Leaked keys

Secret API keys in your page and same-site scripts: Stripe, OpenAI, Anthropic, AWS, GitHub, Slack, Supabase service_role and private keys. Anything found is shown redacted.

Placeholder buttons

Buy, checkout and signup links still pointing at example.com, localhost, # or a leftover placeholder like LS_CHECKOUT_URL.

Mixed content

Scripts, styles and images loaded over plain http:// on an https page.

Security headers

HSTS, Content-Security-Policy, X-Content-Type-Options, clickjacking protection and Referrer-Policy.

Broken links

Up to 25 links on the page, your own first. If a link times out or fails a secure connection, we say we couldn’t check it instead of calling it broken.

How it works: we only make normal GET and HEAD requests. We don’t submit forms, sign up, log in or test for exploits. We don’t store your results; we keep only basic server logs. We won’t scan private or internal addresses.
